# 拉线底盘（HopeA3）

首页「原始 CAN 总线应用」中的独立 app，结合 MHF5010 拉线、方向编码器与
HopeA3 三轮底盘的真实 HexMeow 电机控制。独立 HopeA3 app 仍可单独使用。

## 参考版本与协议

以 `string_chassis` 的 **main / 20133accb224eed665c9308de05181e9a653c15e**
为准，不使用该仓库的 DM-H3510 功能分支。控制核心、编码器驱动及原有协议测试
随工程保存，构建不依赖相邻仓库的位置或当前分支。
源文件映射和适配范围见 [UPSTREAM.md](../src-tauri/crates/mhf-pull-cord/UPSTREAM.md)。

- MHF5010 / DHF50：Classic CAN 1 Mbps，8 字节标准帧，CAN ID 为 `0x140 + 电机 ID`。
- A2 速度闭环；变化的限矩先写 `C1 1E` 并核对回包，再发送同限矩的 A2。
- 每次显式启动均重写 RAM 速度 PID、最大速度、加速度；不写电机 ROM。
- 实测线速大于 `0.005 m/s` 采用出线限矩，小于 `−0.005 m/s` 采用收线限矩，
  中间采用静止限矩。按线长增加末端提醒，再受总限矩封顶约束。
- 归零要求实测线速绝对值低于 `0.02 m/s` 连续 600 ms，默认超时 20 s。
- 角度与 A2 反馈超过 150 ms、状态超过 400 ms 进入故障停机。
- 停机依次尝试零全局限矩、A2 零速、停止、关闭，并读取状态确认。
  启动或停机失败时保留节点与 CAN 会话，供再次停机；不能直接重新使能。

## 连接和使用

1. 在首页打开「拉线底盘（HopeA3）」。打开页面、加载参数、连接 CAN 均不会启动电机。
2. MHF5010 与方向编码器共用经典 CAN 接口。Linux 默认 `can1`，须先将接口配置为
   1 Mbps、FD 关闭并置为 UP。应用读取校验配置，不修改系统接口。
   USB-CAN 可填写 `gs_usb0` / `gs_usb1`，应用按 Classic 1 Mbps 打开。
3. 默认电机 ID 1，编码器节点十进制 16（`0x10`）。连接后向编码器发送定向 NMT Start，
   订阅位置、磁状态和心跳。编码器没有有效反馈时显示等待状态，不伪造角度。
   方向中心角默认 275°，来自本机已保存的装配配置。首次打开时从底盘保存配置或
   编译默认配置读取中心角。底盘启动或应用跟随参数后，显示中心与
   底盘运行参数同步；修改显示中心不能代替设置底盘的编码器中心参数。
4. 核对半径和收线方向后点击「启动 / 归零」，完成后进入运行。
   「重新归零」使用同样的归零流程；「停机并关闭电机」也可在启动等待期间使用。
5. 分别观察已确认的驱动全局限矩、A2 帧内目标及反馈电流。
   原始限矩范围为 0–2000，最大力矩映射参考仅影响显示比例，不换算电流为物理力矩。
6. 编码器固件零点需在拉线电机停止后显式设置；先核对产品身份，再写入、读回并检查
   新位置帧。该零点与拉线电机的机械止挡归零是两项不同操作。

切换工具、断开连接、关闭窗口均进入停机清理。普通断开未确认关闭时报告失败并保留会话。
拉线和底盘的两个接口作为同一应用共同占用 CAN，与其他原始 CAN 应用、分析仪和固件更新互斥。

## 真实底盘跟随

1. 将三个 **HexMeow** 底盘电机连接到另一个 CAN-FD 接口，节点为十进制 **21 / 22 / 23**，
   主机节点 10。Linux 默认 `can0`，USB-CAN 默认 `gs_usb1`。仲裁段 1 Mbps，数据段默认
   5 Mbps；Linux 接口需预先配置为 UP，界面数据段速率需与实际配置一致。
   拉线仍使用 Classic 1 Mbps，不能和底盘共用同一接口。
2. 点击「连接底盘」。此时只建立连接；先完成拉线归零，确认方向编码器反馈有效。
3. 选择「实时设备」、身后跟随 / 身前引导、前端 / 后端出线，再点击「启动真机跟随」。
   该操作复用 HopeA3 的固件识别、标定读取、MIT 初始化和 500 Hz 三轮控制。
4. 跟随核心以参考主分支的 100 Hz 状态机为基础。线长和线速决定纵向运动；方向偏角
   控制车身转动，**前进 / 后退，不横移**。车身正角速度为逆时针，正编码器偏角为顺时针，
   可通过「转向反相」适配装配方向。
5. 步速同步、线长修正、长线制动、猛拉停车和收线确认重启基于参考逻辑。
   步速估计采用三个电机的真实速度反馈；界面展示目标速度、实测速度、位姿和各电机状态。
   「切换身前线长」在发车前和运行中均生效，包括已进入步速同步的身后跟随。
   实时线长达到阈值（例如本机配置的 1.0 m）时，优先进入切换制动；指令归零且
   实测纵向速度不超过 ±0.02 m/s 后，若线长仍达到阈值，则进入身前引导。
   恰好等于阈值时身前目标速度为零，超过阈值后按原身前线长 / 线速规则起步。
   制动中线长回摆或反馈缺失不会提前解除制动；停稳后按当前线长选择运行方向。
   切换制动不低于当前步速同步、停止线或已触发的猛拉制动；界面依次显示
   「切换制动」和「身前引导」，无需停机更改模式选择框。
   身前引导采用反向的左右转向映射（自动切换和直接选择均适用），切换制动结束后生效；
   「转向反相」、转向死区与角速度限幅继续生效。
6. 实时跟随增加「回收超速制动」：实测线速为负且收线速率**达到或超过**设定阈值时，
   优先制动并将转向目标归零，适用于身后、身前及步速同步。减速度取本 app 当前配置的
   普通、停止线、切换、自适应、猛拉、回放重启和步速同步减速度中的最大值
   （编译默认参数为 **3.0 m/s²**），不受基础加速度或线速滤波延迟影响。
   默认勾选「使用收线目标速度」，随拉线模块**已应用到运行**的收线目标速度更新
   （编译默认 **2.0 m/s**）；取消勾选可填写独立正数阈值，点击「应用并保存参数」生效。
   线速提前回落仍会完成制动；指令归零、实测平移及转向停稳，且收线速率低于阈值的
   95% 后解除制动，清除旧跟随估计并按当前线长、线速重新跟随。持续快速回收时保持停车。
   界面显示「回收超速制动」、实际运行阈值及制动减速度；手动台架不启用此实时设备保护。
   旧版底盘配置缺少 `retract_brake_speed_mps` 时自动采用收线目标速度，数值覆盖和自动模式
   （`null`）均随底盘参数保存。

手动测试与参考工程一致：选择「手动测试」并「使能手动台架」后仍保持零指令；
编辑线长、线速、角度只改变草稿，点击「应用手动输入」才执行，并持续到再次应用、
「释放手动输入」或停机。此模式直接驱动真实底盘，无需拉线设备。

「立即停机 / Esc」停止并确认三个底盘电机失能，不停止拉线模块。
拉线的「停机并关闭电机」、重新归零、主连接断开、切换工具或关窗会同时停止底盘。
实时拉线反馈或编码器角度超过 150 ms、拉线运行会话失效、底盘反馈异常或跟随循环超时
均停止跟随；恢复反馈不会自动重启。初始化或停机失败时保留会话，先再次停机确认才能启动。

运行中的参数须点击「应用并保存参数」生效；停止时「保存配置」仅保存下次启动模板，
位于应用配置目录的 `pull-chassis.json`。输入来源、跟随模式、出线侧和转向反相必须停机修改。
当前编译默认参数采用 2026-11-17 本机保存的配置：实时设备、身后跟随、后端出线，
步速同步开启，目标线长 1.2 m，停车余量 0.2 m，编码器中心 275°。
身后启动 / 分界 / 停车 / 身前切换线长分别为 0.7 / 0.9 / 1.39 / 1.6 m。
最高跟随、负速度参数和底盘线速度上限均为 1.6126842288427603 m/s
（显示约 1.6127 m/s，对应 154 mm 轮径的 200 rpm）。
保留参考控制器的 200 RPM 调参范围，按 HopeA3 的 154 mm 轮径
换算为约 1.613 m/s；转向角速度默认上限 1.5 rad/s。电机 KD 和限矩沿用 HopeA3 默认值，
详见 [HopeA3 协议与几何](hopea3.md)。

## 参数

本机没有保存配置时和「恢复默认」均采用随程序编译的完整配置快照：

- [拉线默认参数](../src-tauri/defaults/pull-cord.json)：来自本机 `pull-cord.json` 的 `pull_cord` 对象。
- [HopeA3 底盘默认参数](../src-tauri/defaults/pull-chassis.json)：以本机完整的 `pull-chassis.json` 为基础，按要求将直行限速同步为 200 rpm 对应的线速度。

两份 JSON 通过 Rust `include_str!` 编入程序，其他电脑首次编译运行无需复制本机配置文件，
也不依赖相邻的 `string_chassis` 仓库。已有本机保存配置始终优先；「恢复默认」只更新草稿，
保存后才覆盖本机模板。控制协议与算法以前述参考主分支为基础，并扩展了运行中的
身前阈值切换；原始上游默认文件保留用于追溯。

本次拉线配置与参考主分支数值一致：

| 参数 | 初始值 |
|---|---:|
| 卷筒半径 / 总线长 | 0.026 m / 3 m |
| 收线方向 | 负向 |
| 归零 / 收线速度 | 2.0 / 2.0 m/s |
| 出线 / 静止 / 收线限矩 | 100 / 150 / 200 raw |
| 归零 / 末端 / 总封顶 | 200 / 200 / 300 raw |
| 映射参考 | 2048 raw |
| 速度 Kp / Ki / Kd | 20 / 0 / 0 |
| 加减速斜率 | 2500 °/s² |

「应用到运行」提交当前草稿，驱动完成必要的 RAM 回包核对后才更新运行状态中的配置。
「保存到本机」仅保存下次使用的模板，不改变运行参数或启动电机，文件位于应用配置目录的
`pull-cord.json`。「恢复默认」仅修改表单草稿。卷筒半径和收线方向需停机修改。

保存范围包括拉线控制参数、底盘跟随与步速参数、模式 / 输入来源 / 出线侧 / 转向反相、
中心角、速度和加速度限制，以及三个电机的 KD 和限矩。**关闭时不会自动保存未提交的草稿**：
拉线需点击「保存到本机」，底盘需点击「保存配置」或「应用并保存参数」。
CAN 接口、数据段波特率、拉线电机及编码器节点选择、手动测试临时输入不属于上述保存配置；
首次打开仍使用平台连接默认值。使能状态、归零过程和位姿不恢复，必须显式连接并启动。
