# 瓴控 MHF 电机控制与初始化

依据《电机 CAN 总线通讯协议 V2.36》和《MHF 电机驱动系统用户使用手册》。本模块使用单电机标准帧，报文 ID 为 `0x140 + 电机 ID`，数据长度 8 字节。总线使用 Classic CAN；`gs_usb` 当前只提供 1 Mbps 配置，Linux SocketCAN 可在页面配置协议列出的 100/125/250/500/1000 kbit/s。

## 电机状态兼容

`0x9A` 回复中的 `DATA[6]` 为电机状态，`DATA[7]` 为故障标志。V2.36 第 6 页只定义开启 `0x00` 和关闭 `0x10`；MHF5010/DHF50 已有实测记录为关闭命令 `0x80` 后返回 `0x20`、运行命令 `0x88` 后返回 `0x30`，再次关闭后回到 `0x20`，故障字节均为 `0x00`。

页面和后端同时支持这两组状态：`0x00/0x30` 显示开启，`0x10/0x20` 显示关闭。初始化会先关闭已开启的电机，再核对无故障；运行后按之前的关闭状态核对 `0x10→0x00` 或 `0x20→0x30`，确认成功后才能发送运动目标。参数写入、保存和重启仍要求关闭且无故障，断开时也必须确认关闭。其他状态值继续视为未知，不按位推测其含义。

## 初始化流程

1. 在 `other → 瓴控 MHF 电机控制` 选择 CAN 接口。SocketCAN 先检查接口，再配置为与电机一致的波特率、关闭 CAN-FD 并启动；连接时后端再次核对接口。
2. 连接独占的 CAN 会话，扫描 ID 1–32，或手工选定 ID。扫描只读取状态，不发送运动命令。
3. 点击“初始化所选电机”：读取状态 `0x9A`；若电机处于运行状态，发送关闭 `0x80` 并核对关闭状态；若有故障，发送 `0x9B` 并再次核对故障字节为零。关闭会清除电机转动圈数和先前控制指令。
4. 逐项读取 V2.36 的控制参数 `0xC0` 和设定参数 `0x40`，核对设定 ID，并读取实时状态 `0x9A`、`0x9C`、多圈角度 `0x92`。固件明确返回空参数回复的项目显示为不可用，其余项目继续读取；电机 ID、总线类型和 CAN 波特率必须可读。只有电机仍关闭且无故障才标记初始化完成。
5. 根据需要调整参数。控制参数 `0xC1` 写入 RAM 后立即生效；设定参数 `0x42` 写入后，发送 `0x44` 并核对保存成功，再重启或重新上电。修改 ID、总线类型或 CAN 波特率后，须按新通信参数重新连接。
6. 参数处理完成后，点击“运行” `0x88`，核对状态，再发送运动目标。停止 `0x81` 保持使能；关闭 `0x80` 清除之前的运动命令。安全断开会关闭本会话已使能的电机。

初始化和参数写入均不会自动运行电机。写参数前后均检查电机已关闭且无故障；写后读取同一参数核对。设备重启后，页面尝试再次关闭新 ID 下的电机；如果通信参数已改变，页面释放旧会话并提示按新参数重新初始化。

## 通讯与固件参数兼容

请求和回复共用相同 CAN ID。关闭 `0x80`、运行 `0x88`、停止 `0x81` 均先等待命令回显，再读取 `0x9A` 核对状态；相邻事务间留出 2 ms。状态和参数读取超时最多尝试 3 次，写入和运动目标不自动重发。命令回显丢失后仍须读到符合要求的实际状态；无法确认关闭时保留会话并报告断开失败，供再次关闭。

2026-10-10 在本机 `can0`、电机 ID 1 上逐项只读核对：8 项 RAM 参数、4 项通信设定和 3 项设定 PID 正常返回；`0x40 05 E0/E2/E4/EA/EC` 均返回 `40 00 00 00 00 00 00 00`，未带所请求的参数地址。页面将最大功率、最大速度、最大角度、电流斜率和速度斜率这 5 项设定标为不可用，不把空回复解读为数值零。后端写入前也要求读到正确参数地址和值。带正确地址的零值仍按有效参数处理；真正的超时或无效数据继续报错。

## 页面可设置的参数

下表是 V2.36 提供了 CAN 地址和编码的参数。页面会显示协议地址、实际读值、允许范围，并按协议整数精度写入。

| 类别 | 参数 | 协议范围 | 说明 |
| --- | --- | --- | --- |
| RAM `0xC0/0xC1` | 位置/速度/电流环 Kp、Ki、Kd | 每项 0–2000 | 立即生效，断电丢失 |
| RAM `0xC0/0xC1` | 转矩电流限制 | 0–2000 | MHF 比值；直接转矩电流命令 `0xA1` 不受此限制 |
| RAM `0xC0/0xC1` | 速度限制 | 0–600000，0.01°/s 每单位 | 页面以 °/s 显示 |
| RAM `0xC0/0xC1` | 角度限制 | 0–2147483647，0.01° 每单位 | 页面以度显示 |
| RAM `0xC0/0xC1` | 电流斜率、速度斜率 | 0–30000、0–600000 | 电流斜率在 MHF 使用手册中标为暂未开放 |
| 设定 `0x40/0x42` | 电机 ID、总线类型、RS485/CAN 波特率 | ID 0–32、总线 0–2、波特率为协议枚举值 | ID 0 表示由拨码开关决定；通信修改在保存和重启后生效 |
| 设定 `0x40/0x42` | 最大功率、最大速度、最大角度 | 0–2000、0–600000、0–2147483647 | 后两项在协议设定参数表未注明换算，页面显示协议原始值 |
| 设定 `0x40/0x42` | 电流斜率、速度斜率 | 0–30000、0–600000 | 电流斜率在 MHF 使用手册中标为暂未开放 |
| 设定 `0x40/0x42` | 位置/速度/电流环 Kp、Ki、Kd | 每项 0–2000 | `0x44` 保存到 ROM，重启后生效 |

MHF 使用手册还提到温度、电压、堵转等保护、旋转方向、刹车电阻和校准电压。V2.36 的 CAN 参数表没有这些项目的地址或编码；页面会提示这一限制，不发送猜测的参数写入。使用手册与 CAN 协议对部分速度上限的描述也不一致，页面采用 CAN 协议列出的报文范围，未注明单位的设定值保留原始整数。

## 代码位置

- `src-tauri/src/lingkong.rs`：会话、扫描、初始化状态机、运行门控、安全关闭、参数操作与重启。
- `src-tauri/src/lingkong_params.rs`：V2.36 参数地址、范围、字节编码和解码。
- `src-tauri/src/lingkong_commands.rs`：Tauri 命令入口。
- `src-tauri/src/host_can.rs`：Linux SocketCAN 状态核对和主机接口配置。
- `src/components/LingkongMotorPanel.tsx`：初始化、状态、参数和运动控制页面。
- `src/lingkongParameters.ts`：页面参数名称、范围、单位与选项。
